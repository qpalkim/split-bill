### 기능 버그 체크

- 참여자 동일 이름으로 등록 불가(Input 에러 메시지 표시)
- 참여자 최대 등록 가능한 인원 제한(Input 에러 메시지 표시)
- 지출 내역 최대 등록 몇 개까지 가능한지 제한(Input 에러 메시지 표시)
- 다양한 상황에서도 계산에 오류가 없는지

### 리팩토링

- 불필요한 코드, 제거 가능한 코드 있는지 체크
- 작성했지만 어디에서도 import 하지 않는 타입이나 함수가 있는지 체크
- 설치했지만 사용하지 않는 패키지, 라이브러리가 있는지 체크
- 로드맵 파일의 테스트 체크 미표시 되어 있는 거 테스트
- 코드 파일 경고 없도록 체크(현재 BottomActionBar 파일 등)
  - 노란 줄 뜨지 않도록

### UX 수정

- 토스트 알림을 위로 변경(아래에 뜨니까 버튼과 겹침)
- 모바일 iOS로 테스트 시, 이미지 다운로드가 안 됨(파일, 갤러리 X)
  - PC에선 다운로드 정상 작동
- 첫 화면 브라우저 기기 공유 안내 문구 좀 더 거슬리지 않게 변경
  - 토글 형식으로 수정 고려
